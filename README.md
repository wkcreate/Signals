# CryptoSignals — аналитика крипторынка (спот + фьючерсы + новости)

## Установка
    pip install -r requirements.txt
    python run.py            # живой дашборд
    python run.py once       # один проход
    python run.py backtest BTCUSDT 15m 1000   # проверка стратегии на истории

## Что внутри
- Данные: публичные API Binance, Bybit, OKX (без ключей). Цена = медиана по биржам; если одна недоступна — работает на остальных.
- Фьючерсы: funding rate и динамика Open Interest (перегретые лонги/шорты, подтверждение движения).
- Новости: RSS (CoinDesk, Cointelegraph, Decrypt, Bitcoin Magazine, The Block) + индекс Fear & Greed. Оценка тональности с затуханием по времени, отдельно по каждой монете.
- Анализ: EMA 20/50/200, MACD, RSI, ATR, Bollinger, ADX (определяет тренд/флэт) + фильтр по старшему таймфрейму.
- Сигнал: ЛОНГ / ШОРТ / ЖДАТЬ, вход, стоп (по ATR), TP1/TP2, ориентировочное время удержания, объём позиции под ваш риск.
- Отдельный бот на каждую пару: добавляйте в config.json -> "pairs" (можно свой timeframe/threshold на пару).
- Telegram: впишите token и chat_id в config.json — уведомления только при новом сигнале.

## Настройка (config.json)
threshold — порог скора (выше = реже, но строже), sl_atr — стоп в ATR, rr — отношение прибыль/риск,
deposit и risk_pct — для расчёта объёма, refresh_sec — частота обновления (по умолчанию 10 с).

## Важно
- Ни один инструмент не предсказывает рынок и не гарантирует прибыль. Это фильтр и расчёт рисков, не прогноз.
- Бэктест проверяет только техническую часть (истории новостей/фандинга в бесплатных API нет). Перед реальными деньгами: бэктест на разных монетах и периодах, затем 2–4 недели на демо/без денег.
- Не рискуйте больше 1% депозита на сделку; с плечом осторожнее.
- Если Binance заблокирован в вашей стране, система продолжит работать через Bybit/OKX.

## Работа через GitHub (свой сервер не нужен)
Что где работает:
- GitHub Actions — каждые 30 минут сам анализирует рынок и шлёт сигналы в Telegram, ведёт журнал (journal.csv) и пишет итоги прошлых сигналов.
- Codespaces — живой дашборд, пока он открыт (обновление раз в 20 с).

Шаги:
1. Создай ПРИВАТНЫЙ репозиторий на GitHub и загрузи в него всё содержимое папки (включая скрытые папки .github и .devcontainer). Проверь, что файл .github/workflows/signals.yml появился.
2. Telegram: создай бота у @BotFather (получишь токен), свой chat id узнай у @userinfobot.
3. Settings -> Secrets and variables -> Actions -> New secret: TG_TOKEN и TG_CHAT. Те же два секрета добавь в раздел Codespaces.
4. Вкладка Actions -> разреши workflows -> signals -> Run workflow. В логе шаг «Доступ к биржам» покажет, какие биржи доступны с серверов GitHub.
5. Дашборд: Code -> Codespaces -> Create codespace. Откроется порт 8000 (приватный). В Codespace сначала выполни python run.py check.

Ограничения: серверы GitHub находятся в США/Европе, часть бирж может блокировать такие адреса — система продолжит работать на доступных. Лимит бесплатных минут Actions для приватных репозиториев ограничен (при запуске раз в 30 мин обычно укладывается; проверь текущие лимиты). Codespace засыпает при простое. Секунда-в-секунду «в облаке без твоего участия» GitHub не даёт — для этого нужен постоянный сервер.

## Защитные фильтры (config.json)
- btc_filter: альт не берётся против сильного движения BTC на 1ч.
- min_atr_pct: при слишком низкой волатильности сигнала нет (комиссии съедят прибыль).
- max_signals: одновременно активны только лучшие N сигналов (крипторынок сильно коррелирует — риск не должен складываться в десяток сделок). Остальные помечаются «лимит».
- В карточке: цены по биржам и разброс, срок актуальности сигнала.

## Все пары с бирж
"pairs": "auto" — при каждом старте (и раз в 6 часов) список строится заново из Binance, Bybit и OKX: все USDT-пары с суточным оборотом от min_volume_usd (по умолчанию 2 млн $), без стейблкоинов и плечевых токенов. auto_top: 0 — все, или число — только N самых ликвидных. Нагрузка снижена: топ-30 (multi_top) считается по трём биржам, остальные — по первой ответившей (1 запрос на пару). Явный список тоже работает: "pairs": [{"symbol": "BTCUSDT"}, ...].

## Проверка сигналов (журнал и статистика)
Каждый сигнал пишется в journal.csv: время, вход, стоп, TP1, TP2, срок актуальности. Лимитный вход (entry_mode: limit, limit_atr: 0.25) — это уровень чуть лучше рынка. Для каждого сигнала проверяется по свечам: дошла ли цена до входа (иначе «не исполнен»), затем что было раньше — тейк или стоп, достигнут ли TP2. Если в одной свече коснулись и стопа, и тейка — засчитывается стоп. R считается с комиссиями.
Смотреть: вкладка «Журнал и статистика» в дашборде или python run.py report. Там винрейт с 95%-интервалом против безубыточного, итог в R, просадка, исполнение лимиток, разбивка по стороне и по уверенности. Вывод «преимущество вероятно» появляется только после 100+ закрытых сделок.
Бэктест (python run.py backtest, optimize.py) тоже моделирует лимитные входы. Свечи для проверки берутся с одной биржи (Bybit, при недоступности — другие).

## Графики и избранное
Клик по карточке открывает график как в TradingView (библиотека Lightweight Charts от TradingView): свечи, объём, EMA 20/50/200, линии входа, стопа и тейков, таймфреймы 5m/15m/1h/4h, масштаб колесом, прокрутка мышью. Звезда на карточке — избранное (хранится в браузере); избранные всегда видны вверху и во вкладке «Избранное». Поиск — поле вверху. Для графика нужен интернет (библиотека подгружается с CDN).

## Что улучшено
- Оценка новостей: если задан секрет ANTHROPIC_API_KEY (Codespaces/Actions/переменная окружения), заголовки оценивает Claude (смысл и затронутые монеты); без ключа — словарь ключевых слов. Режим виден в шапке дашборда.
- В дашборде — реальный результат прошлых сигналов (по journal.csv); пока закрыто меньше 30 сигналов, дашборд предупреждает, что доверять деньги рано.
- В Actions сохраняется история Open Interest между запусками.
- График не зависит от CDN: если библиотека не загрузилась, рисуются свечи встроенным кодом.

## Приложение на телефон (иконка на экране «Домой»)
Интерфейс — PWA (папка docs/): открывается как обычное приложение, работает без адресной строки. Три способа получить данные:
1. Дома/на сервере: python run.py serve, открыть http://адрес:8000 в браузере телефона. На Android установка как приложения требует HTTPS; на iPhone «На экран Домой» работает и по http.
2. Codespaces: открыть адрес порта 8000 на телефоне (нужен вход в GitHub, Codespace должен быть запущен).
3. Всегда доступно (рекомендуется): Actions раз в час считает сигналы и публикует ЗАШИФРОВАННЫЙ снимок в отдельный публичный репозиторий-витрину (GitHub Pages бесплатно работает только из публичных репозиториев, а сайт публичен всегда, поэтому данные зашифрованы: AES-256-GCM, ключ из твоего пароля; код стратегии остаётся в приватном репозитории).
   Настройка:
   а) Создай пустой ПУБЛИЧНЫЙ репозиторий, например cryptosignals-app.
   б) ssh-keygen -t ed25519 -f key -N "" ; публичный ключ (key.pub) добавь в Settings -> Deploy keys витрины с правом записи; приватный (key) — секрет ACTIONS_DEPLOY_KEY в основном репозитории.
   в) Секреты основного репозитория: PAGES_REPO = твойлогин/cryptosignals-app, PAGES_PASSWORD = длинный пароль (слабый пароль можно подобрать перебором).
   г) Запусти workflow signals. В витрине: Settings -> Pages -> Deploy from branch -> gh-pages.
   д) На телефоне открой https://твойлогин.github.io/cryptosignals-app/ , введи пароль. iPhone: Поделиться -> На экран «Домой». Android (Chrome): меню -> Установить приложение.
   Снимок обновляется раз в час; мгновенные уведомления — через Telegram.
